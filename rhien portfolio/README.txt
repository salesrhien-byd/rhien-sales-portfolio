RHien NICASIUS T. SALES — PORTFOLIO SETUP

CONTENTS
- index.php: complete PHP portfolio page
- style.css: matching black-and-white responsive design
- resume.docx: editable Word résumé starter
- assets/profile-photo.jpg: profile photo (if included)

INSTALL
1. Extract this ZIP.
2. Copy the extracted folder into your XAMPP htdocs directory, for example:
   C:\xampp\htdocs\rhien_portfolio
3. Start Apache in XAMPP.
4. Open http://localhost/rhien_portfolio/
5. Keep index.php, style.css, resume.docx, and the assets folder together as shown.

NOTES
- This portfolio uses PHP and CSS only; no JavaScript is required.
- Replace placeholders in the résumé with verified details before applying for jobs.
- Add only certificates and achievements you have actually earned.
